# Documentação dos Crawlers

## Google Search Crawler
Busca informações da empresa na web para extrair menções e notícias recentes. Usa Rate Limiting e rotação de headers.

## Receita Federal Crawler
Consulta a API pública `brasilapi.com.br` para encontrar dados sobre CNPJ (Status, Endereço, Sócios e Capital Social).

## Reclame Aqui Crawler
Busca informações de reputação para empresas B2C ou mistas, extraindo taxas de resolução de problemas.
